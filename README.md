# Ударник

Статический тренажёр ударений на 190 учебных карточек. Серверная часть и сборка не требуются: разместите `index.html`, `styles.css`, `app.js`, `words.js`, `favicon.svg`, `robots.txt` и `sitemap.xml` в одной папке статического хостинга.

## Обновление интерфейса 16 сентября 2026

Главная собрана по общей центральной оси, упорядочены отступы и высота карточек. Исправлена рамка программного фокуса заголовка; фокус кнопок и поля поиска остаётся видимым. Заголовки внутренних экранов центрированы, на узких экранах кнопка возврата находится отдельной строкой. Уточнены цвета, тёмная тема, подписи и размеры элементов управления. Стили вынесены в `styles.css`, закрыт контейнер приложения.

В словаре сохранена буква «ё» из нормативного написания. Поиск принимает «е»/«ё», любой регистр и комбинируемый знак ударения; выбранный фильтр доступен скринридерам. Добавлены метаданные страницы, canonical, robots.txt и sitemap.xml. Настройки статического развёртывания — в `vercel.json`.

Локальный просмотр: `node serve.cjs`, затем http://127.0.0.1:4173. Сервер слушает только локальный компьютер. Инструкция публикации — [DEPLOYMENT.md](DEPLOYMENT.md).

## Изменения

- Главная кнопка «Начать тренировку», подсказка выбора ударной гласной, настоящие кнопки и управление с клавиатуры.
- Раздельные идентификаторы карточек. Для «Отзыв» и «отзЫв» добавлены контекстные фразы. Пересчитаны индексы гласных.
- Умное повторение включает недельные карточки после наступления срока. После ошибки карточка возвращается через 10 минут. Счётчик показывает оставшиеся ответы; повторный вход открывает вводный экран, а завершение серии не означает «всё выучено».
- Общая статистика учитывает все режимы, в том числе обоих участников битвы. История ошибок сохраняется; правильно отработанные карточки исключаются из отдельной очереди «Повторить мои ошибки».
- Марафон хранит дневной набор и сохраняет прогресс сразу после ответа. Норма — 10 ответов независимо от правильности; серия увеличивается только за полностью пройденный день. Даты считаются в часовом поясе устройства.
- План марафона проходит все 190 карточек до нового круга. Неотвеченные карточки переносятся на следующий день. Полное прохождение словаря не является гарантией его запоминания.
- Разрешено масштабирование страницы, добавлены видимый фокус и объявления обратной связи для скринридеров. Улучшены стили тёмной темы и поддержка уменьшения анимации.
- Сообщение о сбое загрузки больше не предлагает отключать антивирус.

## Сохранения

Данные по-прежнему хранятся только в `localStorage` текущего браузера и сайта. Обновление файлов на прежнем домене сохраняет доступ к этим данным; другая локальная копия или новый домен имеют отдельное хранилище.

Общие счётчики и история ошибок сохраняются. Однозначные старые записи объединяются с новыми идентификаторами. Старые неоднозначные ошибки «отзыв» остаются в истории без приписывания одному из значений; для отработки предлагаются обе карточки.

Однозначные интервальные сохранения переносятся из `ege4_smart` в `ege4_smart_v2`. Для двух значений «отзыв» старый общий прогресс нельзя достоверно разделить: они начинают повторение заново. История марафона сохраняется, серия пересчитывается по дням с десятью ответами. Старые даты, записанные в UTC, сохраняются как есть; надёжно восстановить местное время прежних ответов невозможно.

При блокировке хранилища тренажёр может работать, но сохранение прогресса не гарантируется.

## Проверка

При установленном Node.js 18+:

```sh
node --test tests/regression.test.cjs
```

Проверки используют изолированное хранилище, управляемые часы и минимальную модель DOM. Покрывают миграцию данных, очередь ошибок, все режимы, подсчёт экзамена, недельное повторение, местную полночь и охват словаря марафоном. Интерфейс дополнительно проверен в браузере.

Список слов и нормативные ударения из исходной версии сохранены. Полная сверка с актуальным словарём ФИПИ в это обновление не входит.
