# Публикация «Ударника»

Проект: https://github.com/ilya71-svg/udarnikk. Основной адрес: https://udarnikk.ru/.

## Обновить существующий проект Vercel

1. Открыть pull request с обновлением интерфейса, проверить изменения и объединить его в `main`.
2. В Vercel открыть существующий проект сайта. В Settings → Git проверить связь с `ilya71-svg/udarnikk` и производственную ветку `main`.
3. В Deployments найти развёртывание нового коммита и дождаться `Ready`. Если автоматическое развёртывание не запустилось, проверить подключение GitHub к проекту.
4. Для этого HTML/CSS/JS сайта Framework Preset — `Other`, Root Directory — корень репозитория, Build Command — пустая строка, Output Directory — `.`. Эти настройки также зафиксированы в `vercel.json`. Node-сервер `serve.cjs` используется только локально.
5. Открыть Production URL в приватном окне браузера и проверить тренировку, словарь и загрузку `styles.css`, `words.js`, `app.js` без ошибок.

Если проекта в Vercel ещё нет: Add New → Project → импортировать этот репозиторий, выбрать указанные настройки и Deploy. Создавать дубликат существующего проекта не нужно.

## Домен и доступ посетителям

В Settings → Domains проверить, что `udarnikk.ru` назначен именно этому проекту и имеет статус `Valid Configuration`. Если Vercel показывает требуемые DNS-записи, сверить их с панелью DNS у регистратора. Копировать значения из текущей панели Vercel: не подставлять IP из старых инструкций. После проверки DNS Vercel должен выпустить HTTPS-сертификат.

Сначала проверить адрес развёртывания `*.vercel.app`, затем собственный домен. Если первый работает, а второй нет, проблема вероятнее связана с доменом, DNS или сертификатом. Если оба недоступны, проверить статус развёртывания и его журналы. Если посетитель видит требование входа в Vercel, проверить настройки Deployment Protection для Production; изменение защиты должно быть осознанным решением владельца.

На момент проверки 16 сентября 2026 DNS домена возвращал A-записи `216.198.79.65` и `216.198.79.1`, но запрос из встроенного браузера завершился тайм-аутом. Это не доказывает глобальную недоступность и не определяет причину. Панель Vercel запросила вход, поэтому настройки проекта и статус Production не проверены.

## Поисковые системы

После публикации проверить `/robots.txt` и `/sitemap.xml`, затем отправить https://udarnikk.ru/sitemap.xml в Яндекс Вебмастер и Google Search Console. Код подтверждения Яндекса сохранён. Доступность по ссылке и появление в поиске — разные этапы; индексация не происходит мгновенно и не гарантируется.

## Сохранения и откат

Прогресс хранится в браузере на прежнем домене. Его структура и идентификаторы карточек этим обновлением не меняются. У посетителя другой браузер или другой домен будут иметь отдельную статистику.

Если после релиза обнаружится проблема, в Vercel можно вернуть предыдущее исправное Production-развёртывание, а исправление кода подготовить отдельным коммитом.
